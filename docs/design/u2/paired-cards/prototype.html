Approved reorder rule: pair reordering changes the occupied matched positions in the export schema; unmatched outputs keep their current positions. Use Output order to move any output across all positions.

Keyboard: Tab to a card and press Enter, then select its counterpart. On a pair grip, Alt+↑ / Alt+↓ reorders that pair. Escape cancels selection. The column menu offers the same move actions.

Later recipes: a destination can show “Fixed value”, “Combines 2 sources” or “Calculated value”. Its settings open contextually; no extra nodes or permanent forms. These capabilities are not implemented by this prototype.
