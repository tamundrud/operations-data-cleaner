# Browser-only CSV conversion (U2)

U2 follows KTD-01–06/09–10: React/strict TypeScript/Vite, native labelled controls and ordinary CSS; Papa Parse with array records and no type inference/blank skipping; strict Zod version-1 grammar; Vitest/Playwright. No router, store framework, backend, persistence or Excel dependency. The pure engine has no UI/DOM/storage/network dependencies. All finite recipe tags exist in the contract; this build rejects capabilities beyond copy/text/required/max-length instead of partially executing them. Types and date/rounding metadata are configuration only until their later units.

A module worker owns the full parsed table and evaluated results. UI receives original source samples and requested result pages (50 rows), full counts, and current issues. A tagged request carries sequence, dataset and revision; mismatched replies are ignored, export must match the completed revision, and configuration edits invalidate download/safety acknowledgement. Failed source replacements preserve the previous dataset. Cancel/crash terminates the worker and blocks exports; retry reparses the active File and current mapping in memory. Source corrections are not present in U2. Downloads are local Blob bytes with URLs revoked after use.

CSV limits are provisional resource budgets: 25 MiB input, 200 columns, 2 million parsed cells and 30-second watchdog. Strict UTF-8 and a quote-position check complement Papa's errors. First nonblank header; normalize by boundary trim, internal whitespace collapse and lower case. Entirely empty data rows are skipped/counted; whitespace is preserved as meaningful text. Logical record and physical starting-line provenance include embedded newlines. Required validation considers whitespace-only text absent without changing its value; maximum length counts Unicode code points, not UTF-16 units. No totals detection or 10,000-row cap.

Output defaults are UTF-8/no-BOM/comma/header/CRLF with a final CRLF. Formula-like headers and copied text produce visible warnings and a current escaped/raw choice. Escaped output prefixes only risky text with an apostrophe; raw output preserves logical content with normal CSV quoting. Preview shows that representation before download. Warning-only rows are exportable with that choice; invalid rows block export until U12 enables acknowledged partial export.

Production HTML and the local static preview response both set restrictive CSP (including `connect-src 'none'`). Only bundled same-origin scripts/styles/workers; no injected HTML, executable formulas, telemetry, remote imports or fonts. Interception tests independently observe all context requests/WebSockets, exact static asset/method allowlists, sentinels in filenames/records/field names, console/errors, and empty browser storage. CSP supplements observed privacy evidence; it is not the only assertion. The dev server is not the privacy acceptance environment; response-header qualification on a deployed host remains U13.

Node 24.19.0/npm 11.9.0 were used. npm dependencies are exact pins with registry integrity in the lockfile. TypeScript 6.0.3 satisfies typescript-eslint's peer contract; TypeScript 7 was not adopted because the current linter excludes it. Audit and browser evidence are recorded in the U2 verification report. No workbook package is added to production. Third-party licenses/notices must accompany redistribution.

The early UX checkpoint remains pending an operator/user with basic spreadsheet skills completing upload → map → preview → export and reporting observed friction. Tests and CE reviewers cannot replace that feedback. Reference-laptop performance and actual hosted headers remain later release obligations; cloud measurements are initial evidence only.

Initial measurements and final verification are recorded in [u2-performance.json](u2-performance.json) and [U2 review evidence](../reviews/u2/README.md). Chromium automated evidence passes; Firefox/WebKit binaries could not be installed under this environment's policy. The configured CI checks and genuine user UX approval remain separate outstanding gates.
