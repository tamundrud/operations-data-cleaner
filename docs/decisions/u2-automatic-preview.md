# U2 automatic preview and row matching

Date: 2026-10-13. Scope: existing U2 draft PR; operator UX acceptance remains pending.

The user directed row-aligned source/output matching and automatic preview refresh. The rejected connector-board mockup and KTD-09's original dropdown-primary form cards do not prescribe this revision. There are no connection lines or separate graph state; each source slot reads the destination field's existing copy recipe. Stable field IDs preserve rename/reorder relationships. Source buttons are reusable, searchable, and show original display samples. Native selects and source-select/Match actions provide keyboard alternatives; validation stays in a row disclosure. Template replacement is deliberate and failed template parsing preserves the active draft.

The session controller accepts one operation at a time. UI edits increment a draft generation and immediately invalidate download and any CSV safety choice. A 250 ms debounce submits an immutable workflow snapshot only when the session is idle. The UI remembers which generation was submitted. An older completion cannot mark a newer draft clean; once idle, the latest draft is evaluated. Existing worker request/dataset/revision checks remain authoritative. Pending or stale results are hidden together with their old headers, avoiding positional mislabelling after field removal/reorder. Cancellation/recovery does not automatically loop; Retry preserves the existing recovery boundary. No session, workflow schema or transformation rules are changed.

A Firefox production privacy run exposed an existing Zod capability probe (`new Function`) rejected by the strict CSP. The installed Zod source explicitly documents that the caught probe still reports a security-policy violation. Both application entry points now import the same `z.config({ jitless: true })` bootstrap before constructing schemas. This selects Zod's interpreted path without changing schema constraints or weakening CSP. The engine and format adapters are unchanged; browser privacy and existing schema/byte tests verify the runtime choice.

The source list and destination list can scroll independently because every mapped source stays beside its destination within the same row. The 25-source/30-output case is exercised with exact downloaded column count/data and at desktop/laptop widths. This is automated evidence of behavior/layout, not evidence of ordinary-user discoverability; hands-on U2 approval remains required.
