That commit, its production ZIP guard, all 33 guard tests and archived CE review evidence are preserved unchanged. This report covers the integration added after that checkpoint. ## Dependency and implementation

The official SheetJS CE 0.20.3 tarball returned HTTP 200 from `cdn.sheetjs.com` on 2026-10-17. Its 2,409,319 bytes match the committed U1 SHA-512 integrity exactly. The unchanged tarball is vendored and referenced locally in the root lockfile; the Apache-2.0 license is included with source and static output. The original archive is preflighted before SheetJS receives it, including worksheet discovery. The CDN is never requested by the application. Manual advisory recheck and zero-known-vulnerability `npm audit` results are recorded in the Excel decision and [audit JSON](integration/u9-dependency-audit.json).

The production worker supports one selected worksheet, first-nonblank headers, original worksheet-row references, typed/raw/display/format/formula metadata and explicit calendar interpretation. Native numeric values feed decimal arithmetic; supported display padding feeds text copies. Unsupported display formats and suspicious numeric identifiers warn without inventing lost digits. Referenced usable caches warn that they may be stale; missing/error caches invalidate the dependent row. Neither formulas, source HTML nor hyperlinks are executed. CSV escaping is requested only for actual formula-like output text or headers, separately from Excel uncertainty warnings.

Worksheet discovery and selection retain the committed conversion until successful import. Cancellation terminates the worker; retry reparses the prior active file. Failed replacement imports retain prior export bytes. XLSX templates supply names/order only; worksheet/import/date settings survive local and portable workflow round trips without source rows or filenames.

No local Firefox/WebKit pass is claimed.
