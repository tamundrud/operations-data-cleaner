# Security policy

## Supported versions

This project is in planning. There are no released or supported software versions yet.

## Reporting vulnerabilities

Do not disclose security vulnerabilities in public issues or attach private customer data. If GitHub private vulnerability reporting is enabled, use **Security → Report a vulnerability**. Otherwise contact the maintainer privately through a verified contact method on the maintainer's GitHub profile. Use a minimal synthetic example.

## Planned safeguards (not yet implemented)

- Local-only browser processing; no transmission of uploaded records.
- Defensive treatment of untrusted CSV/XLSX and workflow JSON.
- Explicit handling of formula injection in CSV/Excel exports.
- Browser-network tests to verify the privacy boundary.

No security audit or release assurance is claimed at this stage.
